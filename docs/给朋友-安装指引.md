# 给朋友的安装指引（Codex app 装不了，看这里）

> **一句话结论**：**Codex 桌面 app 装不了这套技能**——它的托管沙箱会隔离 `~/.codex/skills/`，装了也读不到（详见 `session-observer/adapters/codex/README.md` §1.2，对应 openai/codex issue #45802）。
> 想用"自动观察 / 切换"，用下面任一方案；不想折腾就用**方案 A（零安装）**。

---

## 方案 A：零安装 · 手动兜底（最推荐给不想折腾的人）

**任何 AI 都能用，不用装任何东西。**

文件：`context-handoff/templates/fallback-handoff-prompt.md`

1. **旧会话**里发「第 1 段」→ 让 AI 把当前进度写成交接文档；
2. 开一个**新会话**，发「第 2 段」→ 把交接贴进去，让它接着干。

优点：立刻能用、换谁都能用；缺点：得你自己想起来发，没有自动触发。

---

## 方案 B：Kimi（消费级，最接近 Codex 的体验）

> ⚠️ 前提：Kimi 客户端能读 `~/.kimi-code/skills/`（**需实测**——如果 Kimi app 也沙箱隔离，就用方案 A）。

```bash
./install.sh kimi        # 装两个技能到 ~/.kimi-code/skills/
```

- 启用：会话里说「**观察**」。
- 若没反应，说明 Kimi app 也隔离技能 → 退回方案 A。

---

## 方案 C：DSH（最稳，已验证）

> 前提：本机装了 DSH（DeepSeek Harness）。

```bash
./install.sh dsh         # 装两个技能到 ~/.dsh/skills/
# 再把下面这段追加到 ~/.dsh/AGENTS.md 末尾：
#   session-observer/adapters/dsh/AGENTS.snippet.md
```

- 启用：会话里说「**观察**」。
- 硬档（确定性判据）：`node ~/.dsh/skills/session-observer/scripts/check_session.mjs <会话日志> --threshold 3`。

---

## 该怎么选

| 你的情况 | 选 |
|---|---|
| 就想快点用上、懒得装 | **A（零安装）** |
| 用 Kimi，愿意试 | B（不行就退 A） |
| 有 DSH / 愿意折腾 | **C（最稳）** |
| 还在用 Codex | ❌ 别装，Codex app 沙箱隔离，装了也白装 |
