# 豆包适配层（session-observer）

> 豆包（字节）2026-08 起上线「豆包工作」：技能、连接器、工作伙伴、多 Agent、定时任务、任务模式（代码运行）。
> 上一版调研（2026-10-16）写"一无所获"已过时，此处为 2026-11-12 复核结论。

## 1. 安装技能

豆包有「技能」载体（有公开技能市场，已有 doubao-cron-scheduler 类技能）。
具体安装路径与自动加载机制**本技能未证实**，请按「豆包工作 → 技能」的官方入口上传/安装本目录的 `session-observer/`。

## 2. 一句话启用（软档）

在豆包会话里说「**观察**」启用；或把 SKILL.md 的能力卡贴进系统提示，让它每轮自检。

## 3. 定时器（保险丝，软档）

豆包有「定时任务」页（手动启用/禁用/立即执行）。能否被模型程序化建，**需实测**。

## 4. 软档限制（诚实声明）

- 豆包云端大概率读不到本机会话日志，`check_session.mjs` 不可用；
- 判断靠模型对照特征清单自觉（循环风险同 Kimi）；
- 交接物用「自包含形态」粘贴（豆包读不到本机 HANDOFF.md）。
