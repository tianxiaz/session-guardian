# 无技能兜底 · 手动交接 Prompt

> **适用**：会话里**没加载** `session-observer` / `context-handoff` 技能时。
> 典型场景：① 技能装之前就开着的旧会话；② 平台不支持技能；③ 换了个 AI（Kimi / 豆包 / 别的）。
> **用法**：把下面两段分别粘到「旧会话」和「新会话」里。

---

## 第 1 段：在旧会话里发（让它把状态写下来）

```
请把当前会话的状态整理成一份交接文档，我要开新会话无缝接续。
按这个结构写，直接输出 markdown，别省略：

## 1. 我在做什么（目标）
## 2. 已经完成什么（逐项 + 证据/文件路径/命令结果）
## 3. 还没做完什么（逐项，按优先级）
## 4. 关键决策和踩过的坑（哪些别重做、哪些别碰）
## 5. 下一步第一件事

要求：只写你确实做过、有证据的部分；没证据的标注「未验证」。
```

## 第 2 段：在新会话里发（让它接手）

```
接手这份交接，先读它，然后从「下一步第一件事」继续。
交接里没有证据的部分当「未验证」，先核对再干。

交接如下：
<把第 1 段的输出粘在这里>
```

---

## 为什么这样有效

- 旧会话**不需要技能**——"总结自己干了啥"任何模型都会；
- 新会话拿到这份交接，就继承了"做到哪 + 下一步"，不重做、不漏项；
- **只认证据**：交接里没证据的，新会话一律先核对，不靠"我以为你记得"。

## 局限性（诚实声明）

- 这是**手动版**，靠模型自觉，没有 `check_handoff.mjs` 的判绿；
- 不能自动触发，得你自己想起来发；
- 真正的自动化（阈值触发、判绿、开场指令）仍需要装技能。
