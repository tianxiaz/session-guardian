# WorkBuddy 粘贴指令（技能在 WorkBuddy 上的载体）

> 状态：**未实测**（本机无 WorkBuddy）。平台机制来自官方文档逐字引文；配置文件格式未在本机验证。

> 依据（官方逐字）：WorkBuddy 支持读取项目工作目录下的 `.codebuddy/` 项目级配置，
> 行为与 CodeBuddy Code 保持一致；其中
> - `.codebuddy/rules/` —— 项目规则：**规则文件自动加载**并在对应项目会话中生效
> - `.codebuddy/skills/` —— 项目级技能：每个技能为独立目录，包含 `SKILL.md` 定义
> - 用户级：`~/.codebuddy/skills/`；优先级「项目级 > 用户级」；兼容 `CODEBUDDY.md` / `AGENTS.md`
>
> 来源：`docs/_evidence/批L-上下文交接技能/调研-豆包与WorkBuddy.md`
>
> ⚠️ **硬反证**：官方 Permission-Modes 页说明，工作区未信任（受限模式）时
> 「**不自动加载**其中的设置、规则、命令或脚本」。⇒ 自动加载被**工作区信任**闸门控制。

## 部署（三步）

1. 把技能目录放到项目里：
   ```bash
   mkdir -p .codebuddy/skills
   cp -R <技能目录> .codebuddy/skills/context-handoff
   ```
2. 确认**工作区已信任**（否则上面的东西一律不加载）。
3. 把下面的规则片段追加进 `.codebuddy/rules/context-handoff.md`。


## 本平台的中断信号（B 轴：执行中断）

> 触发有三条轴，**B 轴（执行中断）发生时模型往往已没机会写**。完整场景见 `references/triggers.md`。

| 信号 | 对应 `trigger` | 备注 |
|---|---|---|
| Hook 钩子插件（官方只说"在特定时机自动执行操作"） | ⚠️ 未知 | **官方未给事件名与配置格式**，不许臆造 |
| 定时任务 / 项目 Webhook | `checkpoint` | 这是 WorkBuddy 上最接近"定期刷新交接物"的能力 |
| 企业云侧自动化任务 | `interruption`（每个任务新建独立 Session ⇒ 天然需要交接） | 官方原文：「自动化任务…每次执行都会创建独立 Session」 |
| 技能启停只对新会话生效 | — | 交接完**必须新开会话**才看得到效果 |

⚠️ WorkBuddy 自身文档**零规格**说明上下文阈值/压缩比例；CodeBuddy 的 70–92% **不等于** WorkBuddy，不得混引。


## 权限（部署后必做）

```bash
# 复制进 .codebuddy/skills/ 后修权限
chmod -R u+rwX,go+rX <技能目录>
find <技能目录> -name '*.sh' -exec chmod 755 {} +
```

## 必须知道的两条行为

1. **技能启停只对新会话生效**（官方原文：已加载到当前会话的技能在本会话内仍可使用，
   **新发起的会话才会完全生效**）。⇒ 做"技能交接"**必须新开会话**才看得到效果。
2. **技能包是只读的**：官方明确开关技能**不会修改技能包本身的 `SKILL.md`**
   （从 `.agents` 等目录复制安装的技能始终保持原始内容）⇒ 所以不要指望平台替你回写技能；
   交接物 `HANDOFF.md` 要落在**工作区**，不是技能目录里。

## 规则片段（`.codebuddy/rules/context-handoff.md` 内容）

```markdown
# 上下文交接约定

- 长任务在上下文接近上限前，必须做一次**可核验的交接**，不要靠"感觉还剩一点"。
- 交接物是工作区的 `HANDOFF.md`（固定字段：目标与验收／当前状态／关键决定与理由／
  未完成项与下一步／边界与禁区／环境事实／证据入口／待裁决）。
- 首次＝建立；第二次起＝**增量更新**：只改真正变化的节，**未变项逐字保留**，不许重写全文。
- 判据（取不到量化值就如实写 unavailable，不许编数字）：
  `node <技能目录>/scripts/check_handoff.mjs check ./HANDOFF.md`
  退出码非 0 不许宣布交接完成。
- 交接完成后按平台能力选升级档：能自动开新会话就自动；能命令行续接就给一条命令；
  都不行就给**可粘贴开场指令**（`OPENING_PROMPT.md`）。**不要声称做了没做的事。**
- 技能启停只对新会话生效 ⇒ 交接完请**新开一个会话**。
```

## 能力与限制（如实）

| 项 | 结论 |
|---|---|
| 技能自动加载 | ✅ 官方逐字证实（`.codebuddy/skills/` 的 `SKILL.md`；`.codebuddy/rules/` 自动加载） |
| 触发 hooks | ⚠️ 有 Hook 钩子插件（"在特定时机自动执行操作"，官方示例"生成文件后自动检查格式"）+ 定时任务 + 项目 Webhook；但**事件名清单与配置格式官方未给出** ⇒ 不要写没依据的配置 |
| 上下文阈值 | ❌ 自身文档零规格（只在 Changelog 出现"自动压缩 / `/compact` / `/summarize` / 上下文紧张"）。**CodeBuddy 文档里的 70–92% 阈值不等于 WorkBuddy**，不得混引 |
| 自动开新会话 | ✅ **仅企业云侧**：「自动化任务…每次执行都会创建独立 Session」（腾讯云官方）。**桌面端**为手动 `+ 新建任务` |
| CLI 续接 | ❌ 桌面端无（`--continue`/`--resume` 只在 CodeBuddy Code 文档里） |
